# Assignment Tasks

This repository contains the implementation of all assignment tasks. Each task is provided as a separate Jupyter Notebook (`.ipynb` file).

## How to Run

1. Open the folder corresponding to the required task.
2. Open the `.ipynb` file inside the task folder.
3. Run the notebook **cell by cell in sequential order**, starting from the first cell.
4. Make sure all cells are executed in the given order to reproduce the results.

### Repository Structure

```text
.
├── Task 1/
│   └── task1.ipynb
├── Task 2/
│   └── task2.ipynb
├── Task 3/
│   └── task3.ipynb
└── ...
```

Each task contains its own notebook with the complete implementation and experiments required for that task.

## Notes

* Run each notebook **cell by cell** from top to bottom.
* Do not skip cells, as later cells may depend on variables, models, or outputs generated by earlier cells.
* Make sure the required Python packages and dependencies are installed before running the notebooks.
* The notebooks contain the complete code and experimental workflow for their respective tasks.
